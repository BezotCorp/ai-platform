# Security

> [!CAUTION]
> BCAIP is an AI agent platform that may execute commands, access files, call tools, and interact with external systems on behalf of the user.
>
> Agentic systems carry additional risks compared with ordinary chat-based AI systems, including prompt injection, unintended tool use, data exposure, and destructive actions.
>
> To reduce these risks:
>
> - Prefer isolated environments such as virtual machines or containers when working with untrusted content.
> - Review generated code and tool actions before relying on them.
> - Do not provide sensitive or confidential information unless necessary.
> - Require human confirmation for actions that can cause significant or irreversible changes.
> - Review MCP servers, plugins, tools, and other integrations before granting them access.
> - Limit credentials and permissions to the minimum required for the task.
>
> Content retrieved from repositories, websites, documents, tools, or other external systems may contain instructions intended to manipulate an agent. Treat untrusted content as data, not authority.

## Reporting a vulnerability

If you discover a security vulnerability in BCAIP, please report it privately through the repository's **Security** tab using GitHub's private vulnerability reporting feature.

Do not publish exploitable vulnerability details in a public issue before the problem has been investigated and, where appropriate, fixed.

For more information, see [GitHub's guidance on privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).
