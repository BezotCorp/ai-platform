# Community contributor data

Monthly contributor data is stored by year and month.

Example structure:

    community/
    ├── template.json
    ├── 2026/
    │   ├── 10.json
    │   └── 11.json
    └── 2027/
        └── 01.json

Monthly files are the source of truth.

Do not maintain year or global indexes manually. They are generated by
`scripts/generate-community-indexes.js` before the documentation development
server or production build starts.

## Monthly file format

Copy `template.json` to `<year>/<month>.json`.

Example path:

    community/2026/10.json

Example data:

    {
      "month": "October 2026",
      "communityStars": [
        {
          "name": "Example Name",
          "handle": "github-username"
        }
      ]
    }

The build tool validates each file, copies it into `static/community/`, and
generates:

- `static/community/index.json`
- `static/community/<year>/index.json`

The React community page discovers available years and months exclusively
through those generated indexes.
